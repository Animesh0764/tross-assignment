LinkedIn Profile API

Paste a LinkedIn profile URL and a LinkedIn session's cookies. The request runs server-side against LinkedIn's Voyager API and returns structured JSON — nothing is stored.

Use a throwaway/secondary LinkedIn account's cookies, not your primary one. This calls a private, undocumented LinkedIn API, which is against LinkedIn's Terms of Service and can get the account rate-limited or restricted.
